# Monitor Data File Guide


The data files within the Raw Monitor Data folder are organized by experiment. Each experiment is identified by it’s species ID, start date, and monitor number:

[species ID}_[experiment start date y-m-d]_[monitor number]

For example, an experiment done on Larinioides cornutus in monitor 1 starting on June 9, 2025 spiders should be labeled:

LC_2025-06-09_1/

Data files within the folder follow a similar name scheme, but they are additionally identified by the date of their collection:

[species ID}_[experiment start date y-m-d]_[collection date m-d]_[monitor number]

For example, data from the above experiment collected on June 13, 2025 should be called:

LC_2025-06-09_06-13_1.txt
